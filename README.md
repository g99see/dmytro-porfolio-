# 🚀 Senior C++ Engineer Portfolio

This repository contains the source code for my professional portfolio website. The site is designed with a **Cyberpunk/Terminal** aesthetic, reflecting my passion for low-level systems and high-performance computing.

## 🛠 Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+).
- **Visuals:** Chart.js (Performance Metrics), AOS (Animations), Custom Particle System (Canvas API).
- **Hardware Implementation:** Optimized for deployment on **Raspberry Pi Pico 2W** using MicroPython.

## ⚡ Key Features
- **Low-Latency Design:** Minified and optimized for delivery via microcontrollers.
- **Interactive Metrics:** Real-time data visualization of system performance improvements.
- **Responsive UI:** Fully adaptive layout for Mobile, Tablet, and Desktop.
- **Hardware Integration:** Capable of running as a standalone web server on an RP2350 chip.

## 🚀 Deployment
The site is hosted via **GitHub Pages**.

### Local Hardware Setup (Pico 2W)
To host this site on your own Pico 2W:
1. Flash the latest MicroPython firmware.
2. Upload `index.html`, `main.py`, and `secrets.py`.
3. Configure your Wi-Fi in `secrets.py`.
4. Reboot the board.
